Engineering Architecture & Big-Tech Interview Talking Points

1. Idempotency Guarantee

Unique index on idempotency_key at database level + application caching ensures replayed HTTP requests (double-clicks, network reconnects) return cached responses instantly without executing the task twice.

2. Optimistic Locking (@Version)

Eliminates distributed lock manager (Zookeeper/Redis Redlock) overhead. When 20 workers attempt to claim the same queued job, only the first successfully commits version 0 → 1; all others detect version mismatch and gracefully reject.

3. Transactional Outbox Pattern

Guarantees dual-write consistency: inserts the Job record and OutboxEvent atomically inside the same relational transaction, completely preventing the scenario where DB commits but Kafka event publish fails.
